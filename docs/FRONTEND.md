# Frontend overview

The public application is the Next.js App Router frontend in `el-geoushy/`. Setup instructions and the frontend directory map are in [FRONTEND_SETUP.md](FRONTEND_SETUP.md) and [FRONTEND_ARCHITECTURE.md](FRONTEND_ARCHITECTURE.md). This app is an Arabic-first NEW CETRiS product site with an English language toggle. Product copy and settings are editable browser-only demo data; there is no API connection.

The only public pages are home, product, uses, how-to-use, offers, FAQ and contact/location. The admin route is for demonstration only and is not secure or multi-user.
