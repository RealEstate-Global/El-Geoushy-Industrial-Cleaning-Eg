# Deployment

## Frontend MVP

Deploy the Next.js app from `el-geoushy/` using a Node.js 22 runtime. Install with pnpm 12 and build with `pnpm install --frozen-lockfile && pnpm run build`; run with `pnpm run start`. Set the production site URL in the SEO sitemap/robots metadata before publishing; the current `new-cetris.example` domain is a placeholder.

The admin route is a browser-local demo, not a secure administration system. There is no backend service, upload service, shared persistence, or order flow in the MVP. The current product image is an explicit placeholder and should be replaced with approved local product photography before launch.

## Backend

Backend deployment is outside the scope of this MVP. Refer to the future integration plan; no backend changes or integration are included here.
